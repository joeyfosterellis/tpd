# Manifest: Tootsie in the Desert (the game)

Built 5 October 2026 by Claude (Claude Code, cloud session) at Joey's request. This is a
**text-game** in the sense of `THE-MONTH-GAME-SPEC.md` §10.3: anchored to a document, not to
dated records. So it has no timestamps, no coverage score and no month handoff. It does carry a
manifest, and every element is stamped.

Stamps: **SOURCED** (the record says so, and the row names where) · **REMEMBERED** (Joey said
so, with the date) · **UNKNOWN** · **GENERATED** (the model added it).
