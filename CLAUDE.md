# Working rules for this repository

- **Always cite sources.** Every factual claim, quotation, date, figure or external reference in anything written here must name where it came from: a URL, a file path and commit, a document title and date, or the person and the message it came from. If a claim has no source, label it as such (the TPD labels are SOURCED, REMEMBERED, GENERATED, UNKNOWN) rather than presenting it as established.
